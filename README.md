# CC_IoT
Cloud Computing for Internet of Things - Matakuliah  Komputasi Awan untuk Internet of Things
• Bahasa Inggris: Cloud Computing for Internet of Things (CC IoT)
• Bahasa Indonesia: Komputasi Awan untuk Internet of Things
Mata kuliah ini secara khusus mempelajari bagaimana menghubungkan perangkat keras atau sensor (Internet of Things) ke server berbasis internet (Cloud Computing) untuk penyimpanan, pengolahan data, hingga pemantauan jarak jauh seperti yang sedang Anda kerjakan dengan MQTT dan Node-RED.
