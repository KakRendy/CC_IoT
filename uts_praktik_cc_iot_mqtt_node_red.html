Sistem Monitoring Suhu dan Kelembapan Menggunakan MQTT Public Broker dan Node-RED

Buat sistem monitoring suhu dan kelembapan menggunakan Node-RED yang terhubung dengan MQTT Public Broker (EMQX Public atau HiveMQ Public). Sistem menerima dan mengolah data MQTT, menampilkan nilai dan grafik suhu serta kelembapan pada dashboard, memeriksa threshold berdasarkan standar kenyamanan termal/kesehatan lingkungan (seperti Kemenkes RI atau ASHRAE), dan memberikan notifikasi ketika nilai berada di luar batas. Dokumentasikan pengerjaan di Medium.com dengan screenshot.

Contoh Function Node: Threshold & Validasi

                  
                

                
Mencakup konversi numerik, validasi nilai kosong/tidak valid, batas bawah & atas suhu serta kelembapan.

                
const data = typeof msg.payload === 'string'
  ? JSON.parse(msg.payload)
  : msg.payload;

const suhu = Number(data?.temperature);
const hum = Number(data?.humidity);

if (Number.isNaN(suhu) || Number.isNaN(hum)) {
  node.warn("Payload tidak valid / kosong");
  return null;
}

const statusSuhu = suhu < 18 ? "Suhu terlalu rendah"
  : suhu > 30 ? "Suhu terlalu tinggi" : "Suhu normal";

const statusHum = hum < 40 ? "Kelembapan terlalu rendah"
  : hum > 60 ? "Kelembapan terlalu tinggi" : "Kelembapan normal";

const isAbnormal = statusSuhu !== "Suhu normal" || statusHum !== "Kelembapan normal";

msg.payload = {
  temperature: suhu,
  humidity: hum,
  statusSuhu,
  statusHum,
  overallStatus: isAbnormal ? "ABNORMAL" : "NORMAL"
};
return msg;
